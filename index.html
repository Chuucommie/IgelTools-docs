Everything IgelTools, without the marketing.

Functional and technical documentation for the suite, plus the status and conventions of its Model Context Protocol servers. The marketing site explains what the apps are for; this one explains how they work, how to run them and where an agent has a real interface.

Two documentation sites, on purpose. The marketing site (chuucommie.github.io/igeltools-web) is for introducing the apps. This site holds the details: behaviour, protocols, storage, security, limitations and MCP status. If a claim belongs in an implementation, it belongs here.

The suite

Living-room control

Igel TVRemote

A network remote for smart TVs: discovery, pairing, keys, text, wake-on-LAN, 12 App Intents and a macOS MCP server.

Writing and thinking

IgelNotes

A 21-type block editor on SwiftUI and SwiftData, with Pencil drawing, 17 App Intents, Apple Intelligence, optional Appwrite sync and a local MCP server. CloudKit is planned, not active.

Server control

IgelServer

Native macOS and iOS clients for a headless server over SSH: telemetry, systemd, Docker, qBittorrent, SMB shares, an encrypted vault and a Swift MCP server.

Suite management

IgelLauncher

A native SwiftUI macOS suite manager: embedded catalog, CPU-aware asset selection, SHA-256 verification, DMG/tar.gz installs, receipts, updates and a 13-tool MCP server.

For agents

All four apps now expose a Model Context Protocol surface. Three are separate stdio binaries; IgelNotes runs an in-app loopback HTTP server on Mac (the transport can bind on iPadOS, but the iPad UI does not expose it yet). IgelServer adds a foreground-only HTTP server on iOS, reachable over the local network with a bearer token.

# IgelLauncher — catalog, installs, updates (stdio)
IgelLauncher mcp

# IgelServer — profiles, SSH, Docker, systemd, torrents
igelserver-mcp                 # stdio
igelserver-mcp --http          # POST http://127.0.0.1:8787/mcp

# IgelServer iOS — foreground only, Bonjour
http://<device>.local:8788/mcp # Bearer token from Settings

# Igel TVRemote — saved TVs, keys, text, power (stdio)
igeltvremote-mcp

# IgelNotes — in-app HTTP on Mac (iPadOS runtime exists)
http://127.0.0.1:8765/mcp      # Bearer token, Settings → Server MCP

The MCP overview covers transports, registration, scopes, tokens and security. Tools that change state are annotated as non-read-only; IgelServer additionally gates write and destructive tools behind scopes and elicitation.
